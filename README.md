# Thailand 2026 · 双人动态旅行地图

一页式中文旅行手册，覆盖 2026 年 9 月 28/29 日抵达清迈、10 月 4–6 日从曼谷离开的动态行程。默认走清迈深玩与曼谷双城，素可泰、清莱、大城、美功与丹嫩都作为可解释的替换路线。

功能：

- 根据抵达/离开日期生成 5–8 晚路线；
- 可切换清迈深玩、清莱当天往返、素可泰住一晚与清莱住一晚；
- 曼谷第二日可切换水门寺与 Talat Phlu、美功全程小火车、丹嫩加美功效率版、Talat Noi、Siam 雨天线与大城；
- 清迈寺庙压缩为老城两座、山上两座，并加入无骑乘/洗象/表演的大象观察项目；
- 周末日期自动把 JJ Market 放到飞曼谷前的早晨，Nong Ho 作为替换而非叠加；
- 选好日期后可以逐日切换地图，查看当天活动圈、停靠顺序、分段交通与外部导航；
- Leaflet 地图展示清迈、素可泰、曼谷、美功与丹嫩、大城和清莱备选；
- 地图气泡显示地点照片，并可打开统一详情抽屉或独立地点页面；
- 水门寺五个机位、美功铁路换乘节点与核心地点都提供独立介绍、现场观察、雨天处理和来源；
- 区分核心点、可选模块、餐饮、咖啡、交通和雨天室内点；
- 出发前 16 天尝试读取 Open-Meteo 逐日预报；
- 提供雨天替代、城市交通、租车判断、美食和观看清单；
- 路线以用户提供的《Lonely Planet Thailand》为第一次筛选，开放时间与交通用官方来源校准，近期游记只用于判断现场节奏与体验信号。

## Local preview

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## Deployment

站点从 `main` 分支根目录直接发布，不需要构建步骤。

仓库首次发布时，在 **Settings → Pages → Build and deployment** 中选择
**Deploy from a branch**，分支设为 **main**、目录设为 **/(root)**，然后保存。
此后每次推送 `main` 都会自动更新网页。
